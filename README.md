# راهنمای سازگان (Sazgan Guides)

اپ اندروید آفلاین برای راهنما و فایل‌های آموزشی محصولات مهندسی سازگان گستر.

## افزودن محصول و فایل
1. پوشه هر محصول از قبل در `content/` هست؛ PDFها را داخل پوشه همان محصول بگذارید (نام فایل انگلیسی باشد).
3. فایل `product.json` کنار آن‌ها بسازید:
```json
{ "title": "ترازوی ۱۰۰ کیلویی", "summary": "توضیح کوتاه",
  "titles": { "install.pdf": "راهنمای نصب" } }
```

## ساخت APK با گیت‌هاب
هر `git push` روی شاخه main به‌صورت خودکار APK می‌سازد:
گیت‌هاب ← تب Actions ← آخرین Build APK ← Artifacts ← sazgan-guides-apk

## تست روی کامپیوتر
`npm install && npm run dev` و باز کردن http://localhost:8080

## نسخه‌بندی
- شماره نسخه در فایل `VERSION` است (مثلاً `0.3.0`). برای نسخه جدید این فایل را عوض کنید.
- شماره ساخت (build) را گیت‌هاب خودکار می‌دهد و همان `versionCode` اندروید است.
- هر push روی main خودکار APK می‌سازد و در بخش **Releases** ریپو منتشر می‌کند.
- امضای رسمی: اگر در Settings ← Secrets ← Actions این چهار مقدار را بگذارید، APK امضاشده (release) ساخته می‌شود: `KEYSTORE_BASE64`، `KEYSTORE_PASSWORD`، `KEY_ALIAS`، `KEY_PASSWORD`.

## امکانات نسخه ۰.۳.۰
نوار پایین (خانه، محصولات، جستجو، ذخیره‌شده‌ها)، منوی کناری با آیکن، حالت شب، اندازه متن، ظاهر مینیمال، نشانک صفحه، «اخیراً خوانده‌شده».
اطلاعات تماس پشتیبانی را در `content/app.json` پر کنید (phone/email/site).
