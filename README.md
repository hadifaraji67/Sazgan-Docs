# راهنمای سازگان (Sazgan Guides)

اپ اندروید آفلاین برای راهنما و فایل‌های آموزشی محصولات مهندسی سازگان گستر.

## افزودن محصول و فایل
1. پوشه هر محصول از قبل در `content/` هست؛ PDFها را داخل پوشه همان محصول بگذارید (نام فایل انگلیسی باشد).
3. فایل `product.json` کنار آن‌ها بسازید:
```json
{ "title": "ترازوی ۱۰۰ کیلویی", "summary": "توضیح کوتاه",
  "titles": { "install.pdf": "راهنمای نصب" } }
```

## ساخت APK با گیت‌هاب
هر `git push` روی شاخه main به‌صورت خودکار APK می‌سازد:
گیت‌هاب ← تب Actions ← آخرین Build APK ← Artifacts ← sazgan-guides-apk

## تست روی کامپیوتر
`npm install && npm run dev` و باز کردن http://localhost:8080
